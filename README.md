# fieryledlamp-web-flasher

Web Flasher для FieryLedLamp (ESP32 / ESP32-S3).

Прошивка устройства прямо из браузера через Web Serial API.

## Возможности

- Прошивка ESP32 и ESP32-S3 прямо из браузера
- Автоопределение чипа
- Выбор варианта прошивки для ESP32
- Режимы: полная прошивка / только firmware / только littlefs
- Прогресс-бар и журнал прошивки в реальном времени

## Требования

- Браузер на движке Chromium: Chrome, Edge, Opera, Vivaldi, Brave, Яндекс.Браузер
- Firefox и Safari не поддерживают Web Serial API
- Data-кабель USB (не зарядный)

## Использование

1. Откройте страницу Web Flasher.
2. Зажмите кнопку BOOT на плате и подключите её USB-кабелем к компьютеру.
3. Нажмите «Подключиться к ESP» и выберите COM-порт.
4. Выберите вариант прошивки (для ESP32) и режим прошивки.
5. Нажмите «Прошить» и дождитесь завершения.

## После прошивки

Устройство создаст точку доступа `FieryLedLamp`. Подключитесь к ней
и откройте `http://192.168.4.1` для настройки.
