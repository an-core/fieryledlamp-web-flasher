# [fieryledlamp-web-flasher](https://an-core.github.io/fieryledlamp-web-flasher/)

Web Flasher для FieryLedLamp (ESP32 / ESP32-S3).

Прошивка устройства прямо из браузера через Web Serial API!\
Бинарники всегда загружаются с GitHub, поэтому вы получаете самую свежую версию автоматически.

## Возможности

- Прошивка ESP32 и ESP32-S3 прямо из браузера
- Автоопределение чипа и выбор варианта прошивки для ESP32
- Режимы прошивки: полная / только firmware / только littlefs
- Скачивание `.bin` файлов: один, несколько или весь архив `.zip`
  (с показом размера каждого файла)
- Прогресс-бар и журнал прошивки в реальном времени
- Автоматическая загрузка актуальных бинарников с GitHub при подключении

## Требования

- Браузер на движке Chromium:
  Chrome 89+, Edge 89+, Opera, Vivaldi, Brave, Cent Browser, Яндекс.Браузер
- **Firefox и Safari не поддерживают Web Serial API** - прошивка в них невозможна
- Data-кабель USB (не зарядный)
- Драйвер USB-UART, если плата не определяется: CH340, CP2102

## Использование

1. Откройте страницу Web Flasher.
2. Зажмите кнопку BOOT на плате и подключите её USB-кабелем к компьютеру (после подключения кнопку можно отпустить).
3. Нажмите «Подключиться к ESP» и выберите COM-порт.
4. Дождитесь определения чипа и загрузки бинарников с GitHub.
5. При необходимости выберите вариант прошивки (для ESP32).
6. Выберите режим прошивки:
   - **Полная прошивка (все файлы)** - рекомендуется для первого запуска и обновлений
   - **Только firmware.bin** - обновление только прошивки, настройки сохраняются
   - **Только littlefs.bin** - обновление только файловой системы (веб-страницы)
7. Нажмите «Прошить» и дождитесь завершения - прогресс-бар покажет 100%.

## Скачивание .bin файлов

В шаге **3.2** можно скачать нужные бинарники для ручной прошивки через `esptool.py` или другую утилиту.\
Отметьте галочками один или несколько файлов (или скачайте весь архив `.zip`).\
Рядом с каждым файлом показан его размер.

## После прошивки

Если была выполнена **«Полная прошивка»**, устройство создаст точку доступа `FieryLedLamp`.\
Подключитесь к ней и откройте `http://192.168.4.1` для настройки.\
Далее можно указать логин и пароль вашей Wi-Fi сети.

## Частые проблемы

- **«Web Serial не поддерживается»** - вы используете Firefox или Safari.
  Откройте страницу в Chrome, Edge или другом Chromium-браузере.
- **«Failed to fetch»** - проверьте подключение к интернету
  (бинарники загружаются с GitHub).
- **«Порт занят»** - закройте Arduino IDE, монитор порта и другие программы,
  использующие COM-порт.
- **Устройство не запускается после прошивки** - возможно, вы выбрали
  «Только firmware» без совместимой partition table. Прошейте «Полная прошивка».
