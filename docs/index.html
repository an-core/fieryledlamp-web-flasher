Инструкция по прошивке

1. Подготовка
  • Браузер. Требуется браузер на движке Chromium: Chrome 89+, Edge 89+, Opera, Vivaldi, Brave, Cent Browser, Яндекс.Браузер.
  • Firefox и Safari не поддерживают Web Serial API - в них прошивка невозможна. Откройте страницу в другом браузере.
  • Драйвер USB-UART. Если плата не определяется в Диспетчере устройств - установите драйвер: CH340, CP2102.
2. Подключение платы
  • Зажмите кнопку BOOT на плате ESP и подключите к компьютеру USB-кабелем (не зарядным - нужен data-кабель). После чего кнопку BOOT можно отпустить.
  • Нажмите «Подключиться к ESP» - браузер покажет список COM-портов.
3. Определение чипа и выбор варианта
  • ESP32-S3 - флешер покажет список из двух вариантов:
    • Вариант 1 - без MULTI_MATRIX: используется одна LED-матрица (стандартный вариант).
    • Вариант 2 - с MULTI_MATRIX: используется поддержка нескольких последовательно соединённых матриц (до 8 штук 16×16).
  • ESP32 - флешер покажет список из трёх вариантов. Выберите нужный:
    • Вариант 1 - базовый: будильник «Рассвет», режим «Закат», расписание лампы, погода, MQTT, режим «Мультилампа», LED-панель, бэкап настроек, статусы устройств, информация о ПО.
    • Вариант 2 - будильник «Рассвет», режим «Закат», расписание лампы, погода, MQTT, режим «Мультилампа», LED-панель, бэкап настроек, статусы устройств, информация о ПО, плюс поддержка SD-карты.
    • Вариант 3 - SD-карта, расписание лампы, погода, MQTT, LED-панель, статусы устройств, информация о ПО, плюс поддержка нескольких матриц (MULTI_MATRIX).
4. Режим прошивки
  • Полная прошивка (все файлы) - используется по умолчанию и рекомендуется для первого запуска и обновлений. Прошивает bootloader, partition table, firmware и файловую систему.
  • Только firmware.bin - обновление только прошивки. Настройки и файловая система сохраняются. Используйте, если вышло обновление кода, но partitions, littlefs не менялась.
  • Только littlefs.bin - обновление только файловой системы (веб-страницы, настройки). Прошивка остаётся прежней. Используйте, если обновились только HTML/CSS/JS-файлы.
Внимание: при выборе «Только firmware» partition table должна совпадать с той, что уже залита в ESP. Если не уверены - выбирайте «Полная прошивка».
5. Прошивка
  • Нажмите «Прошить».
  • Дождитесь завершения - прогресс-бар покажет 100%.
  • ESP автоматически перезагрузится с новой прошивкой.
6. Во время прошивки
  • Не отключайте USB-кабель!
  • Не закрывайте вкладку браузера!
7. После прошивки
  • Если выполнена "Полная прошивка", устройство создаст точку доступа с именем FieryLedLamp.
  • Подключитесь к ней и откройте http://192.168.4.1 для настройки.
  • Далее можно указать логин и пароль вашей WiFi-сети.
8. Частые проблемы
  • «Web Serial не поддерживается» - вы используете Firefox/Safari. Откройте в Chrome или Edge.
  • «Failed to fetch» - Проверьте интернет.
  • «Порт занят» - закройте Arduino IDE, монитор порта и другие программы, использующие COM-порт.
  • Устройство не запускается после прошивки - возможно, вы выбрали «Только firmware» без совместимой partition table. Прошейте «Полная прошивка».

Модифицированная прошивка FieryLedLamp

Открыть в GitHub

1. Поддерживаемое оборудование
  • ESP32 WROOM
  • ESP32-S3 (N16R8)
  • Дисплей TM1637 (семисегментный индикатор)
  • Дисплей ST7789 (TFT 1.47" 172×320)
  • Сенсорная кнопка (touch TTP223)
  • Тактовая кнопка (физическая кнопка)
  • LED чип APA102 (VCC, GND, DATA, CLK)
  • LED чип WS2812B (VCC, GND, DATA)
  • ИК-пульт (38 кГц)
  • Радиопульт 433 МГц
  • MP3 плеер (DFPlayer mini)
  • SD карта для внешних эффектов JINX в формате .out
2. Динамическое управление модулями

Включение / выключение через web только для ESP32-S3:

  • Дисплей TM1637
  • Дисплей ST7789
  • Кнопка
  • ИК-приёмник
  • RF-приёмник
  • MP3 плеер
  • SD карта для внешних эффектов JINX в формате .out
    • поддержка физической SD карты и эмуляции в LITTLEFS
3. Wi-Fi функционал
  • Мульти-WiFi: запоминание нескольких сетей с автоматическим переключением
  • Автоматическое переподключение при потере сигнала WiFi
4. Работа с LED
  • Динамическая настройка матрицы из нескольких матриц в web без перепрошивки
  • Поддержка до 8 заводских матриц WS2812B 16×16
  • Настраиваемый вывод часов, даты, погодных данных и бегущей строки
  • Количество визуальных встроенных эффектов: 130+
  • Поддержка анимационных эффектов, созданных Jinx Frame Viewer
5. Интеграция с погодными сервисами
  • Яндекс.Погода
  • OpenWeather
6. Отображение информации
  • Вывод времени и погоды на веб-страницу устройства
  • Вывод даты, времени и погоды на дисплей (TM1637, ST7789)
  • Дублирование данных бегущей строкой на матрице (отключается)
7. Аудиовозможности
  • Индивидуальные звуковые мелодии для каждого эффекта
  • Голосовое озвучивание текущего времени и погоды
  • Во время озвучивания активный эффект не останавливается
8. Управление ИК-пультом
  • Выбор готового пульта из списка или добавление собственного
9. Управление кнопкой
  • Количество нажатий для действия настраивается в web
10. Выбор шрифта
  • 3x5 (кроме текста бегущей строки)
  • 5x8
  • 8x13
  • 10x16
11. Гибкое расписание
  • Автоматическое включение/выключение устройства
  • Активация ночного режима (ночные часы)
  • Переключение режима цикла и запуск заданного эффекта по расписанию
12. Дополнительно
  • Синхронное управление несколькими лампами в одной WiFi сети
  • Резервное копирование настроек (экспорт / импорт архива)
  • OTA-обновления (по воздуху)
  • Уведомление о новой версии в модальном окне «Информация о ПО»
  • Статусы устройств (модальное окно с информацией о компонентах)
  • Кликабельные подсказки на web-страницах
  • Пароль для Редактора файлов
  • Автоскрытие пунктов меню, отключённых в прошивке
