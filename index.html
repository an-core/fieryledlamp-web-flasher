Инструкция по прошивке

1. Подготовка
  • Браузер. Требуется браузер на движке Chromium: Chrome 89+, Edge 89+, Opera, Vivaldi, Brave, Cent Browser, Яндекс.Браузер.
  • Firefox и Safari не поддерживают Web Serial API - в них прошивка невозможна. Откройте страницу в другом браузере.
  • Драйвер USB-UART. Если плата не определяется в Диспетчере устройств - установите драйвер: CH340, CP2102.
2. Подключение платы
  • Зажмите кнопку BOOT на плате ESP и подключите к компьютеру USB-кабелем (не зарядным - нужен data-кабель). После чего кнопку BOOT можно отпустить.
  • Нажмите «Подключиться к ESP» - браузер покажет список COM-портов.
3. Определение чипа и выбор варианта
  • ESP32-S3 определяется автоматически - вариант выбирается сам, ничего нажимать не нужно.
  • ESP32 (классический) - флешер покажет список вариантов. Выберите нужный:
    • Вариант 1 - базовый: будильник «Рассвет», режим «Закат», расписание лампы, погода, MQTT, режим "Мультилампа", LED-панель, бэкап настроек, статусы устройств, информация о ПО.
    • Вариант 2 - будильник «Рассвет», режим «Закат», расписание лампы, погода, MQTT, режим "Мультилампа", LED-панель, бэкап настроек, статусы устройств, информация о ПО, плюс поддержка SD-карты.
    • Вариант 3 - SD-карта, расписание лампы, погода, MQTT, LED-панель, статусы устройств, информация о ПО, плюс поддержка нескольких матриц (MULTI_MATRIX).
4. Режим прошивки
  • Полная прошивка (все файлы) - используется по умолчанию и рекомендуется для первого запуска и обновлений. Прошивает bootloader, partition table, firmware и файловую систему.
  • Только firmware.bin - обновление только прошивки. Настройки и файловая система сохраняются. Используйте, если вышло обновление кода, но partitions, littlefs не менялась.
  • Только littlefs.bin - обновление только файловой системы (веб-страницы, настройки). Прошивка остаётся прежней. Используйте, если обновились только HTML/CSS/JS-файлы.
Внимание: при выборе «Только firmware» partition table должна совпадать с той, что уже залита в ESP. Если не уверены - выбирайте «Полная прошивка».
5. Прошивка
  • Нажмите «Прошить».
  • Дождитесь завершения - прогресс-бар покажет 100%.
  • ESP автоматически перезагрузится с новой прошивкой.
6. Во время прошивки
  • Не отключайте USB-кабель!
  • Не закрывайте вкладку браузера!
7. После прошивки
  • Если выполнена "Полная прошивка", устройство создаст точку доступа с именем FieryLedLamp.
  • Подключитесь к ней и откройте http://192.168.4.1 для настройки.
  • Далее можно указать логин и пароль вашей WiFi-сети.
8. Частые проблемы
  • «Web Serial не поддерживается» - вы используете Firefox/Safari. Откройте в Chrome или Edge.
  • «Failed to fetch» - Проверьте интернет.
  • «Порт занят» - закройте Arduino IDE, монитор порта и другие программы, использующие COM-порт.
  • Устройство не запускается после прошивки - возможно, вы выбрали «Только firmware» без совместимой partition table. Прошейте «Полная прошивка».
